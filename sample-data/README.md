This directory contains synthetic sample data for development and testing.

ALL files in this directory are SYNTHETIC / FABRICATED for educational purposes.
They do NOT contain real network traffic, real IP addresses, real users,
or any sensitive information.

Contents:
  pcap/   — Sample PCAP files (synthetic network captures)
  logs/   — Sample log files (simulated application logs)
  reports/ — Example generated incident reports

These files are committed to the repository so that anyone cloning the project
can run the full analysis pipeline without generating their own lab traffic first.
